# AGENTS.md

## Project

Docusaurus 3.7.0 help center for [Tango Web](https://tangoapp.dev) — a browser-based Android device management tool using ADB over WebUSB/WebRTC. Deployed to GitHub Pages at `help.tangoapp.dev`.

## Commands

```bash
pnpm start          # dev server (no browser open)
pnpm build          # production build → build/
pnpm typecheck      # tsc (editor support only, not used in CI)
```

- Package manager: **pnpm** (README says yarn — ignore it)
- No test suite, no lint script
- CI: GitHub Actions deploys `build/` to GitHub Pages on push to `main` (Node 22)

## Content structure

- **Docs** (`docs/`) — served at site root (`routeBasePath: "/"`). Sidebar is autogenerated from folder structure. Each category folder has a `_category_.yml` for label/position.
- **Blog** (`blog/`) — one directory per post, named `YYYY-MM-DD-slug/`. Post file is `index.mdx`. Images go alongside.
- **Static assets** — `static/img/` for site-wide assets (logo, favicon).

## Blog post format

```mdx
---
authors: simon
---

# Title

<head>
  <meta name="fediverse:creator" content="@yumechan@mastodon.social"/>
</head>

Intro paragraph(s)...

{/* truncate */}

## Section heading

Content with images, etc.
```

- Frontmatter must include `authors: simon`
- Always include the `<head>` fediverse meta block
- Use `{/* truncate */}` to mark the excerpt boundary
- Author defined in `blog/authors.yml`

## Docs conventions

- Use `.mdx` extension (not `.md`)
- Import the `<Pro />` component to mark features requiring paid plans: `import Pro from "../_pro";` then `<Pro />` or `<Pro team />` or `<Pro feature="Feature name" />`
- Mermaid diagrams are enabled (```` ```mermaid ```` blocks)
- Docusaurus admonitions: `:::info[Title]`, `:::warning`, `:::note`, etc.
- Icons: use `unplugin-icons` with Fluent icon set — `<IconXxx />` auto-imported (e.g., `<IconFluentDevice16 />`)

## Key config details

- `trailingSlash: true` — all URLs end with `/`
- `onBrokenLinks: "throw"` — broken links fail the build
- Local search via `@easyops-cn/docusaurus-search-local` (no Algolia)
- `blogSidebarCount: 0` — blog has no sidebar
- Prettier configured for SVG files via `@prettier/plugin-xml`
- `auto-imports.d.ts` is generated by `unplugin-auto-import` — do not edit manually
